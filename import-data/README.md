# import-data

Taruh di sini (hanya di komputer/server Anda, TIDAK di-commit):

- semua file `*.json` hasil ekspor dari panel Data live Hostinger
  (boleh ada di subfolder; nama file bebas, koleksi dibaca dari isi file)
- folder `uploads/` berisi file upload yang diunduh (logo, foto, lampiran, dll.),
  cukup taruh semua file di situ, nama file harus sama dengan di panel

Lalu jalankan: `npm run import:data` (lihat README-MIGRASI.md).
